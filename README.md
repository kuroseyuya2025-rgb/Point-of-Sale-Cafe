# 104 Brews Cafe POS & Billing System

A Java-based Point of Sale (POS) and Cafe Billing System developed for **104 Brews**.  
The system provides a simple desktop interface for taking customer orders, calculating bills, printing receipts, and viewing transaction records.

## Demo

▶️ **[Watch the POS System Demo](demo.mp4)**

The demo video shows the main workflow of the system, including:

- Login screen
- Cafe menu and product selection
- Adding items to an order
- Quantity management
- Automatic subtotal, tax, and total calculation
- Cash input and change calculation
- Receipt preview/printing
- Transaction records
- Customer number and date searching
- Daily earnings calculation
- Logout

> **Note:** The demo video is about 1 minute and 50 seconds long.

## How to Run

1. Install the **Java Development Kit (JDK)**.
2. Clone or download this repository.
3. Open the project in your Java IDE.
4. Make sure all project files and resources are included.
5. Locate the main/login class of the project.
6. Run the project.
7. Log in and use the POS interface.
